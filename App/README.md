# App — Ikena Makeup (Capacitor)

Native Android (and, in a future PR, iOS) wrapper around the Ikena Makeup
platform, built with Capacitor + Vite + Vue 3 + Pinia + Vue Router +
Tailwind v4, mirroring the stack and versions already used in `frontend/`.

## Setup

```bash
cd App
npm install
```

## Environment: API base URL

`src/services/api.js` reads its `baseURL` from `VITE_API_URL` (resolved by
`src/config/env.js`). `App/.env.development` is committed with a safe
default (`http://10.0.2.2:8000/api`, the Android emulator's loopback alias
to your host machine), so a fresh clone works out of the box for local
development against the emulator — no manual env setup required.

If you need to override that default, e.g. to test on a physical device,
create your own local `App/.env.development.local` (gitignored). This must
be the mode-specific `.local` variant — per Vite's env-file precedence
(`.env` < `.env.local` < `.env.[mode]` < `.env.[mode].local`), only
`.env.development.local` actually outranks the committed
`.env.development`; a plain `App/.env` or `App/.env.local` would silently
lose and you'd still hit the emulator address.

```bash
# App/.env.development.local — physical device on the same Wi-Fi network as
# your dev machine — replace with your machine's LAN IP (ipconfig / ifconfig).
VITE_API_URL=http://192.168.1.100:8000/api
```

```bash
# Production — MUST be HTTPS. env.js's resolveApiBaseUrl() throws at build
# time if a production build (`vite build --mode production`) resolves a
# non-https URL. Cleartext dev-networking exceptions (see
# android/app/src/main/res/xml/network_security_config.xml) are scoped to
# the emulator/LAN dev host only and never apply to production. Inject this
# via the CI/CD build environment, not a committed .env.production file.
VITE_API_URL=https://api.your-production-domain.com/api
```

`VITE_API_URL` can also be passed directly as a shell env var when invoking
Vite/Vitest (`VITE_API_URL=... npx vitest run`), which is how CI should set
it for production builds.

## Scripts

```bash
npm run dev      # Vite dev server
npm run build    # production build -> dist/
npm run preview  # preview the production build
npm test         # vitest run
npm run cap:sync # capacitor sync (copies dist/ into native projects)
```

## Android

The native Android project lives in `android/` (committed, per Capacitor
convention — only its generated/build output is gitignored, see
`android/.gitignore`). Release signing reads from a gitignored
`android/keystore.properties` (see `android/keystore.properties.example`);
without it, release builds fall back to debug signing so
`./gradlew assembleRelease` still runs locally.

**Not yet verified on this machine**: this Android project was scaffolded
via `npx cap add android`, but `./gradlew build` was never run here — this
machine has no JDK 17+ / Android SDK installed (`ANDROID_HOME` /
`ANDROID_SDK_ROOT` unset). The Gradle project structure is real and
generated by Capacitor's own tooling, but it is unverified-by-build. Verify
on a machine with an Android SDK + JDK 17+ before shipping.
